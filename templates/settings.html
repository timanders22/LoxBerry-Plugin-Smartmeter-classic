Ergebnis der Installation

Richtet die signierte Paketquelle von volkszaehler.org ein und installiert das zu dieser Architektur passende vzlogger. Der mitgelieferte Dienst des Pakets wird dabei abgeschaltet - vzlogger wird von diesem Plugin gestartet.

Steht im MQTT-Thema und im UDP-Satz: <Thema>/<Zählernummer>/<Kennzahl>. Wer von der klassischen Betriebsart kommt, trägt hier dieselbe Nummer ein – dann bleiben die virtuellen Eingänge im Miniserver unverändert.
MQTT eingeschaltet, Thema ausgeschaltet
Gilt für beide Betriebsarten. Eingestellt wird es im Reiter MQTT. Im Gateway muss das Abo /# eingetragen sein.
Viele Haushaltszähler haben keine gestellte Uhr. vzlogger verwirft solche Telegramme dann mit „timestamp before 1990, IGNORING“ — der Zähler wird gelesen, aber kein Wert kommt an. Im Zweifel: Rechner-Uhrzeit.

Einbindung in Loxone

Diese Adressen und Namen brauchst du in der Loxone Config. Sie richten sich nach den Einstellungen, die hier im Plugin gespeichert sind.

MQTT

Die Werte gehen über das MQTT-Gateway des LoxBerry an den Miniserver. Im Gateway muss das Abo /# eingetragen sein, sonst kommt nichts an.

Themen des Lesekopfs :

//Consumption_Total_OBIS_1.8.0
//Delivery_Total_OBIS_2.8.0
//Total_Power_OBIS_16.7.0
//Last_UpdateLoxEpoche

Das Gateway ersetzt jeden Schrägstrich durch einen Unterstrich. Ein virtueller Eingang in Loxone heißt deshalb zum Beispiel _<Seriennummer>_Consumption_Total_OBIS_1.8.0. Der Titel muss genau so lauten — das Gateway ordnet über den Namen zu.

UDP — nur wo nötig

Virtueller UDP-Eingang auf Port . Die Befehlserkennung eines Werts sieht so aus:

\i<Seriennummer>:Consumption_Total_OBIS_1.8.0:\i\v

Hinweis: die Legacy-Abfrage ist ausgeschaltet. Dann sendet nur die vzLogger-Betriebsart, falls dort UDP aktiviert ist.

HTTP — zum Nachsehen

http:///plugins//index.php

Liefert alle Werte als Klartext. Als virtueller HTTP-Eingang mit Abfragezyklus 60 Sekunden verwendbar. MQTT ist der empfohlene Weg.

MQTT

Hier wird MQTT eingestellt — an einer einzigen Stelle. Die Einstellung gilt für beide Betriebsarten, vzLogger wie Legacy; in deren Reitern wird sie nur angezeigt.

Darunter veröffentlicht das Plugin je Lesekopf und Kennzahl, zum Beispiel /1234/Consumption_Total_OBIS_1.8.0.

Was im MQTT-Gateway eingetragen sein muss

Ohne dieses Abo kommt am Miniserver nichts an — der häufigste Grund, warum Werte fehlen, obwohl das Plugin sauber sendet:

/#

Einzutragen unter System-Einstellungen → MQTT Gateway → Abonnements. Die Namen der virtuellen Eingänge in Loxone stehen im Reiter Einbindung in Loxone.
